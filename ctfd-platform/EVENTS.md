# فعاليتا الأربعاء والخميس

هذا الوضع اختياري. نشر الكود وحده لا يفعّله ولا يبدأ أي فعالية.
يعمل داخل نسخة CTFd واحدة، مع فصل الوصول في الخادم حسب عضوية الحساب، وليس بفلاتر الواجهة فقط.
لا يلزم إنشاء دومين آخر أو كلمة مرور مشتركة.

## النشر والتفعيل

1. احفظ نسخة Export من CTFd، ونسخة من بيانات Docker وملفات التشغيل قبل الترقية.
2. انشر البرانش على بيئة اختبار أولاً. من `ctfd-platform` شغّل:

   ```bash
   docker compose up -d --build ctfd
   ```

   أعد تشغيل كل عمال CTFd معاً. لا تخلط عمالاً بالكود القديم والجديد.
3. افتح **Admin → Events** أو `/plugins/ctfd-registration/admin/events`.
4. اقرأ تنبيه التفعيل، ثم فعّل الوضع. ينشئ الجدول الجديد تلقائياً؛ لا يعدّل جداول الجولات القديمة.
   التفعيل يغلق التحديات حتى تعيينها ونشرها وبدء فعاليتها. لا يحذف الحسابات أو النتائج السابقة.
5. تظهر فعاليتان مدة كل منهما 180 دقيقة:
   - `/workshops/boys` — الطلاب، الأربعاء.
   - `/workshops/girls` — الطالبات، الخميس.
6. راجع إعدادات Config العامة: حجم الفريق 3، وظهور التحديات للحسابات المسجلة، والتوقيت/الإيقاف العام.
   الإعداد العام `Admins Only` يظل نافذاً. إظهار سكور فعالية يتطلب أيضاً أن يكون Score Visibility العام Public أو Private.
   الموقع يجب أن يعمل على جذر الدومين، مثل `https://ctf.example.com/`.

لا تستخدم `/events` كرابط للفعالية: هذا المسار محجوز لإشعارات CTFd.
ولا تستخدم سكربت `selftest.py` أو تستورد محتوى الجولات أثناء الفعاليات الحقيقية.

## دخول المشاركين

يعطي المنظم كل مجموعة رابطها. الرابط يختار الفعالية، ثم ينقل المشارك إلى تسجيل CTFd المعتاد.
اسم المستخدم والبريد فريدان على الموقع كله؛ الحساب يشارك في فعالية واحدة.
لا يمكن تبديل الفعالية بعد التسجيل، حتى بتغيير الرابط أو طلب API.

بعد التسجيل ينشئ المشارك فريقاً أو ينضم لفريق بكلمة مرور الفريق أو رابط دعوته المعتاد.
يرتبط الفريق بفعالية المنشئ تلقائياً. تُرفض دعوات وعمليات انضمام المجموعة الأخرى.
حقلا التخصص ومستوى الخبرة يبقيان، لكن تصنيف الفريق يتبع الفعالية بدلاً من مستوى خبرة أعضائه.

الحسابات السابقة لا تُنقل تلقائياً. من Events يمكن تعيين حساب غير مشارك وفريقه كله.
الحسابات ذات الحلول أو الجوائز القديمة، والحسابات المسجلة بالفعل في فعالية، لا تُنقل: استخدم حسابات جديدة.
البيانات السابقة تظل متاحة للإدارة. حسابات الإدارة ترى المجموعتين، فلا تستخدمها لفحص تجربة اللاعبين.

## تحضير التحديات والدفعات

1. أنشئ التحدي وملفاته وفلاقه من شاشة Challenges المعتادة.
2. من Events، افتح **اختيار التحديات وتسمية دفعاتها** تحت فعالية اليوم.
3. اختر التحديات، وسمّ دفعاتها مثل «الدفعة الأولى»، «الدفعة الثانية»، ثم احفظ.
4. كل تعيين جديد يبدأ مخفياً. زر **نشر الدفعة** يجعله متاحاً عندما تكون الفعالية مفتوحة.
5. نشر دفعة لاحقة يُبقي الدفعات السابقة. **إخفاء الدفعة** أو **إخفاء التصنيف** يمنع فتحها وتنزيل ملفاتها وإرسال حلولها.
   يمكن إعادة نشرها لاحقاً. لا تُحذف النقاط المكتسبة من تحديات أخفيتها.

يحدّث اللاعب صفحة التحديات لرؤية الدفعة الجديدة. المؤقت يتزامن مع الخادم كل 15 ثانية؛ منع التسليم يطبق فوراً في الخادم حتى لو بقيت واجهة قديمة مفتوحة.

يمكن تعيين تحدٍ واحد للفعاليتين مع نشر مستقل. استخدم نسخاً مختلفة إذا أردت تقليل تسريب طريقة الحل بين اليومين.
التحديات تستخدم نقاطاً ثابتة؛ Dynamic scoring مرفوض عند تعيين التحدي. مكافأة الحل المبكر لا تطبق في هذا الوضع.
لا تعدّل قيمة التحدي بعد بدء أي فعالية: قيمة التحدي في CTFd مشتركة، وتعديلها يغيّر قيمة الحلول السابقة.
الرايت أب وملفات الحل تظل عند المنظم ولا تُرفع ضمن ملفات اللاعبين.

## التشغيل وقت الحدث

| الإجراء | النتيجة |
|---|---|
| بدء الفعالية | يبدأ وقتها ويغلق تسجيلها؛ تظهر الدفعات المنشورة فقط |
| نشر دفعة | يضيف تحدياتها دون إغلاق التحديات السابقة |
| إخفاء تصنيف | يخفي تحديات التصنيف لهذه الفعالية فقط ويمنع تسليمها |
| إظهار تصنيف | يعيد إتاحة تحديات التصنيف المعيّنة لهذه الفعالية |
| تعديل الوقت المتبقي | يحدد الدقائق الباقية من لحظة التعديل، وليس مدة كلية جديدة |
| إيقاف مؤقت | يوقف الساعة والتسليم وتشغيل بيئات جديدة؛ يمكن قراءة التحديات المنشورة |
| استئناف | يكمل الساعة بعد استبعاد وقت التوقف |
| إغلاق استقبال الحلول نهائياً | يخفي التحديات ويرفض الحلول حتى بالروابط المباشرة؛ النتائج تبقى |
| إظهار السكور لهذه الفعالية | يعرض ترتيبها ونقاطها فقط، مع احترام إعداد الظهور العام |

عند نفاد الوقت يغلق الخادم استقبال الحلول تلقائياً، حتى إن بقيت صفحة اللاعب مفتوحة.
الفعالية المنتهية لا تبدأ من جديد. لا توجد فعالية «بروفة» منشأة تلقائياً.
إغلاق الحلول لا يقتل حاويات Docker فوراً: قد تبقى خدمات التحديات شغالة حتى انتهاء مهلة Whale، لكنها لا تقبل نقاطاً جديدة.

## الفصل وحدوده

- قوائم المستخدمين والفرق، الملفات الشخصية، ترتيب النتائج والرسم البياني تخص فعالية الحساب.
- الروابط وطلبات API إلى حسابات المجموعة الأخرى مرفوضة. أعداد الحلول وقوائم حالّي التحدي محصورة بالفعالية.
- إخفاء السكور يغطي الملفات الشخصية والـAPI الخاصة أيضاً؛ الإدارة تظل ترى النقاط.
- يمنع الخادم التشغيل/التنزيل/التسليم للتحديات غير المنشورة أو بعد الإغلاق، بما في ذلك مسارات Whale.
- هذه فعاليات داخل منصة واحدة، وليست عزلاً لخوادم Docker أو قاعدة البيانات. الإعدادات العامة والإشعارات العامة مشتركة؛ لا تنشر إعلاناً خاصاً بمجموعة عبر الإشعارات العامة.
- التقييمات وفتح حلول التحديات عبر API العام غير متاحين في وضع الفعاليات. التلميحات الفردية المدفوعة/المجانية تتبع صلاحية التحدي.
- اختيار اليوم قائم على التسجيل الذاتي. من يعرف الرابط الآخر يستطيع إنشاء **حساب جديد** فيه؛ لا توجد آلية تحقق من هوية الحضور أو منع الغرباء.

## الاختبارات

تعمل اختبارات التكامل على CTFd 3.8.7 بقاعدة SQLite مؤقتة. تعزلها عن قاعدة الإنتاج، ولا تشغل Docker challenges.
من جذر المستودع على جهاز به Docker:

```bash
docker run --rm --user root --entrypoint python \
  -e PYTHONPATH=/opt/CTFd \
  -v "$PWD:/ctf:ro" \
  -v "$PWD/ctfd-platform/plugins/ctfd-registration:/opt/CTFd/CTFd/plugins/ctfd-registration:ro" \
  -v "$PWD/ctfd-platform/plugins/ctfd-rounds:/opt/CTFd/CTFd/plugins/ctfd-rounds:ro" \
  -v "$PWD/ctfd-platform/themes/tuwaiq:/opt/CTFd/CTFd/themes/tuwaiq:ro" \
  ctfd/ctfd:3.8.7 \
  -m unittest discover -s /ctf/ctfd-platform/tests -v
```

تشمل الاختبارات التسجيل، الفريق، قوائم الأعضاء، الروابط المباشرة، السكور والرسم البياني، الدفعات، الوقت، الإغلاق، CSRF، والتوافق مع تعطيل وضع الفعاليات.
اختبار Whale يستخدم مساراً بديلاً للتحقق من صلاحيات الخادم؛ يلزم اختبار تشغيل حاوية حقيقية في بيئة الاختبار قبل النشر للإيفنت.

للرجوع عن التفعيل قبل استخدامه، استرجع نسخة قاعدة البيانات السابقة مع الإصدار السابق من الكود.
بعد وجود مشاركات جديدة لا تسترجع نسخة قديمة دون حفظ تلك النتائج؛ لا يوجد زر لإعادة تعيين النقاط تلقائياً.
